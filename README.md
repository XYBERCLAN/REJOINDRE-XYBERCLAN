 # Join XYBERCLAN Community

If you'd like to join the XYBERCLAN Community, please submit a request by creating an issue using the template below.

## How to Request to Join

1. Go to the **Issues** tab.
2. Click on **"New Issue."**
3. Select the **Join Request** template.
4. Fill in your full name, email address, and a brief explanation of why you want to join.
5. Click **"Submit new issue."**

We will review your request and send you an invitation!

> [!TIP]
> **Make your membership public**: Once you've joined, if you want the **XYBERCLAN** badge to appear on your GitHub profile, go to the [**People**](https://github.com/orgs/CYBERCLAN237/people) tab in the organization, find your name, and change the visibility from **Private** to **Public**.

# Rejoindre la communauté XYBERCLAN
Comment faire une demande pour rejoindre ?
GitHub c'est comme un site web où les développeurs partagent leurs projets. Pour rejoindre XYBERCLAN, tu dois y créer une sorte de ticket de demande. Voici comment faire, étape par étape :
1. Va sur la page GitHub de XYBERCLAN et clique sur l'onglet "Issues" (c'est comme une boîte à messages).
2. Clique sur le bouton "New Issue" (= Nouveau message).
3. Choisis le modèle "Join Request" (= Demande d'adhésion).
4. Remplis le formulaire avec :

Ton nom complet
Ton adresse email
Une courte explication de pourquoi tu veux rejoindre

5. Clique sur "Submit new issue" (= Envoyer). C'est tout !
L'équipe va lire ta demande et t'envoyer une invitation.

💡 Astuce — Afficher ton badge XYBERCLAN sur ton profil :
Une fois que tu as rejoint, si tu veux que les gens voient que tu fais partie de XYBERCLAN sur ta page GitHub :

Va dans l'onglet "People" (= Membres) de la page XYBERCLAN
Trouve ton nom
Change la visibilité de "Private" (privé) à "Public" (public)

Ton badge apparaîtra alors sur ton profil GitHub pour que tout le monde puisse le voir ! 🎖️
